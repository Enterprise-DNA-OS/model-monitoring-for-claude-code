# Why a database and commands

The recurring job is to compare a reference with current evidence, understand missing outcomes and record the next action. An agent runs the commands and presents the result. The database holds the evidence and the review history. Read-only HTML supplies the weekly dashboard, definition card and remediation brief.

A screen gives live navigation, interactive charts, phone access and a shared session experience. This local desk does not provide those, offline synchronisation or real-time alerts. The rendered files do not enforce per-reader access. Enterprise DNA can build the screens and shared controls a business needs into its version. /new-view adds a read-only report; /customise extends the records and rules with tested migrations.

The agent is the door. The data remains yours and works with Claude Code, Codex, OpenCode or Cursor. Omni by Enterprise DNA can install, customise and operate the system.
