# /review

Inspect source windows, comparisons and open actions first. Use --model, --review-due, --retention-review-due, --evidence and the actual --actor. Dates are agreed business review dates, never invented legal deadlines.

Run `npm run monitor -- review` with the required flags listed by `npm run monitor -- help`. Use --json when reading data programmatically. Finish the work and report the result here. Do not send, publish, change the deployed model or delete source evidence.
